# Festival of Learning Activity

**Can I Trick Your Brain in 30 Minutes?** — an interactive, self-contained HTML activity.

## ▶️ Run the activity

Clicking `index.html` on GitHub only shows the source code, not the running page. Use one of the links below instead — they open the activity live in your browser:

- **[Launch the activity](https://raw.githack.com/Utman5454/Festival-of-Learning-Activity/main/index.html)** — works immediately, no setup needed.

### Want a permanent link instead?

Turn on GitHub Pages once and GitHub will host it for you at a stable URL:

1. Go to **Settings → Pages** in this repository.
2. Under "Build and deployment", set **Source** to `Deploy from a branch`.
3. Set **Branch** to `main` and folder to `/ (root)`, then **Save**.
4. After a minute, the activity will be live at `https://utman5454.github.io/Festival-of-Learning-Activity/`.
